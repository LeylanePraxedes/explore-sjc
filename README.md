# 🗺️ Explore SJC

Guia interativo de São José dos Campos com informações sobre história local, recomendações de museus, parques e restaurantes.

Desenvolvido como projeto prático de estudos em HTML e CSS.

---

## ✨ Funcionalidades

- 📍 Mapa estilizado com rotas e pontos de interesse
- 🏛️ Recomendações de museus e pontos históricos
- 🌿 Parques e áreas de lazer
- 🍽️ Restaurantes e gastronomia local
